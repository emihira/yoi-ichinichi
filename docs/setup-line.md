# LINE公式アカウントと Messaging API の準備

このサービスでは、ご家族ごとに **LINE公式アカウントを1つ** 用意します。親御さんとご家族は、このアカウントを友だち追加して使います。

所要時間：約20分（LINEアカウントでログインできれば、ほかに用意するものはありません）

> LINE の管理画面は、ときどき見た目や名前が変わります。この手順と画面が違うときは、Claude Code に「画面に○○と出ています」と伝えてください。

---

## 手順1　LINE公式アカウントを作る

1. パソコンのブラウザで **LINE for Business の「LINE公式アカウントの開設」ページ** を開く（検索欄で「LINE公式アカウント 開設」と調べると出てきます）
2. 「**LINEアカウントでログイン**」を押し、ふだん使っている LINE でログインする
3. 作成フォームを入力する
   - アカウント名：例 `よい一日のはじまりに`（親御さんのトークに表示される名前です）
   - メールアドレス：ご自身のもの
   - 業種：「個人」に近いもの（例：大業種「個人」→ 小業種「個人（その他）」）
   - 運用目的・主な使い方：近いものを選べば大丈夫です
4. 「確認」→「完了」を押す
5. 「**LINE Official Account Manager へ**」を押して管理画面を開く

✅ 確認：管理画面の左上に、作ったアカウント名が出ていれば完了です。

## 手順2　Messaging API を使えるようにする

Messaging API は、プログラムから LINE のメッセージを送ったり受け取ったりするための仕組みです。

1. 管理画面の右上にある **「設定」**（歯車のマーク）を押す
2. 左のメニューで **「Messaging API」** を押す
3. **「Messaging APIを利用する」** を押す
4. 「プロバイダー」を作る画面が出たら、名前を入れて作る（例：`ご自身の名前の見守り`）
   - プロバイダーは「アカウントの持ち主」の名前です。親御さんには表示されません
5. プライバシーポリシー・利用規約の URL は **空欄のまま** で「OK」を押す

✅ 確認：「Channel ID」と「Channel secret」が表示されれば完了です。
⚠️ **Channel secret はここでコピーしたり、チャットに貼ったりしないでください。** 手順6でコマンドを使って直接登録します。

## 手順3　自動の返事をオフにする

LINE公式アカウントには、最初から「自動で返事をする」機能がオンになっています。これが動くと、親御さんにこのサービスの返事と二重に届くため、オフにします。

1. 管理画面の右上 **「設定」** → 左のメニュー **「応答設定」**
2. 次のように切り替える

| 項目 | 設定 |
|---|---|
| チャット | **オフ** |
| あいさつメッセージ | **オフ** |
| Webhook | **オン** |
| 応答メッセージ | **オフ** |

（画面によっては「応答時間」の設定もあります。触らなくて大丈夫です）

## 手順4　ベーシックIDを控える

1. 管理画面の右上 **「設定」** → **「アカウント設定」**
2. 「ベーシックID」（`@` で始まる英数字。例：`@123abcde`）をメモする

このIDは秘密情報ではありません。親御さん用の登録リンクを作るときに使います（`wrangler.toml` の `LINE_OA_ID` に入れます）。

## 手順5　チャネルアクセストークンを発行する

チャネルアクセストークンは、プログラムが「このアカウントとして送信してよい」と証明するための合言葉です。

1. ブラウザで **LINE Developers コンソール**（`developers.line.biz/console/`）を開き、同じ LINE でログインする
2. 手順2で作ったプロバイダー → その中のチャネル（アカウント名と同じ名前）を押す
3. 上のタブで **「Messaging API設定」** を押す
4. いちばん下の **「チャネルアクセストークン（長期）」** の **「発行」** を押す

⚠️ 表示されたトークンも **コピーしてチャットに貼らないでください**。画面は開いたままにして、手順6に進みます。

## 手順6　秘密情報を Cloudflare に登録する

ここからはターミナル（黒い画面）での操作です。Claude Code が案内します。

```bash
npx wrangler secret put LINE_CHANNEL_SECRET
npx wrangler secret put LINE_CHANNEL_ACCESS_TOKEN
npx wrangler secret put ADMIN_SETUP_CODE
```

- 1つずつ実行すると「Enter a secret value:」と聞かれるので、そこに貼り付けて Enter を押します（入力した文字は画面に出ません）
- `LINE_CHANNEL_SECRET`：手順2の Channel secret（LINE Developers の「チャネル基本設定」タブにもあります）
- `LINE_CHANNEL_ACCESS_TOKEN`：手順5のトークン
- `ADMIN_SETUP_CODE`：あなたが決める合言葉（英数字16文字以上）。最初に管理者として登録するときに、LINE で一度だけ送ります

## 手順7　Webhook URL を設定する（プログラムを公開した後）

Webhook URL は「LINE にメッセージが届いたとき、知らせる先」の住所です。

1. LINE Developers コンソール → チャネル → **「Messaging API設定」** タブ
2. 「Webhook設定」の **「編集」** を押し、次を入れて「更新」
   `https://yoi-ichinichi.<あなたのサブドメイン>.workers.dev/webhook`
   （プログラムを公開したとき、ターミナルに表示される URL の末尾に `/webhook` を付けたもの）
3. **「検証」** を押し、「成功」と出ることを確認する
4. **「Webhookの利用」** をオンにする

## 手順8　料金プランを確認する

1. 管理画面の右上 **「設定」** → **「利用と請求」** → **「プラン」**
2. **「コミュニケーションプラン」**（無料）になっていることを確認する

無料プランでは、こちらから送るメッセージ（朝の挨拶・リマインド・家族への通知）は **月200通まで** です（2026年11月時点の想定。最新の条件はこの画面で確認してください）。親御さんやご家族からのメッセージへの返事は、この数に入りません。

---

## 最後に：管理者として登録する

1. 自分のスマートフォンで、管理画面の「友だち追加ガイド」の QR コードを読み取り、友だち追加する
2. トークに `ADMIN_SETUP_CODE` に登録した合言葉を送る
3. 「管理者として登録しました。」と返ってくれば完了です
