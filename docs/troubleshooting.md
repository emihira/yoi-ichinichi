# よくあるトラブルと対処

困ったときは、Claude Code に「○○が起きています」と話しかけてください。このページを見ながら一緒に調べます。

## 朝のメッセージが届かない

| 確かめること | 方法 |
|---|---|
| 登録した当日ではないか | 登録した日は送りません。翌朝からです |
| お休み中ではないか | ご家族の LINE で「ようす」。「休止中」と出ていたら「さいかい」 |
| 送る時刻 | 「ようす」の「〜の予定」。変えるときは「じかん」 |
| ブロックされていないか | 「ようす」に「ブロックまたは削除されているため」と出たら、親御さんの LINE でブロックを解除してもらう |
| 今月の送信数 | 管理者の「ようす」の最後に出ます。無料プランは月200通まで |
| 自動のタイマー（Cron）が付いているか | Cloudflare の画面で、Worker の［設定］→［トリガー］に「Cron」が出ているか確かめる。無料プランは1アカウントで5つまで。足りないときは、使っていない Worker のタイマーを外すか、最低限 `*/5 20-23,0-3 * * *`（見守り）だけを付ける。すぐ試すには、`DEMO_MODE` が `"true"` なら管理者が「デモ：朝」 |
| プログラムが動いているか | Claude Code に「Cloudflare のログを見て」と頼む（`npx wrangler tail`） |

## 何度も通知が来る、と親御さんに言われた

まず管理者の「ようす」と、親御さんのトーク画面で、実際に届いたメッセージの数を確かめてください。

- 届いたのが1通なら、スマホが「読んでいない通知」を繰り返し鳴らしています。高齢者向けのスマホ（らくらくスマートフォンなど）によくある機能です。読めば止まります。
- このサービスが送るのは、朝のメッセージ1通と、返事がないときのリマインド1通（60分後）だけです。

## 「招待コードが正しくないか、有効期限が切れています」と出る

- 招待コードは発行から24時間、1回だけ使えます。管理者が「しょうたい」から発行し直してください。
- 1時間に5回まちがえると、しばらく受け付けなくなります。1時間ほど待ってください。

## LINE Developers の「検証」で失敗する

- Webhook URL の最後が `/webhook` になっているか確かめる。
- `npx wrangler secret list` で `LINE_CHANNEL_SECRET` が登録されているか確かめる。値を貼りまちがえた可能性があれば、登録し直す。

## 親御さんの返事に、二重に返事が出る

LINE公式アカウントの「応答メッセージ」がオンになっています。`docs/setup-line.md` の手順3のとおり、オフにしてください。

## 送信できなかったお知らせがある、と出る

管理者の「ようす」の最後に件数が出ます。主な原因は、今月の送信数の上限、または相手がこのアカウントをブロックしたことです。Claude Code に「送信の失敗を調べて」と頼むと、記録（`notification_failures` の表）から原因を確かめます。
